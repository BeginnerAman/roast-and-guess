# 🔥 Roast & Guess — Party Game

An interactive, real-time multiplayer party game designed for 2–6 players. Roast your friends anonymously, vote on spicy questions, and guess who wrote which burn! 

Built with **HTML5, TailwindCSS, GSAP**, and powered in real-time using **Firebase Realtime Database**.

---

## 🎮 Game Rounds

### 🗳️ Round 1: Vote & Roast
* A funny, provocative question is displayed (e.g., *"Who is the laziest?"*).
* Everyone votes on who fits the description best.
* The player with the most votes gets **roasted** publicly with a hilarious, dynamically generated burn message! 🔥
* Every participant receives +2 points just for playing along.

### ✍️ Round 2: Anonymous Messages
* Everyone anonymously drafts a spicy or secret message about other players.
* Once submitted, the app compiles all messages.

### 🕵️ Round 3: Guess Who Wrote It
* Match the anonymous messages to the correct player who wrote them!
* Earn **+10 points** for every correct guess.
* The player with the highest total points at the end wins the ultimate trophy! 🏆

---

## ⚡ Features

* **Zero Login Required:** Enter a nickname, create or join a room, and instantly jump into the chaos.
* **Real-time Synchronization:** Powered by Firebase Realtime Database to keep all screens perfectly synced without manuals refreshes.
* **Sleek Glassmorphic UI:** Built with dark-themed Tailwind CSS, custom modern gradients, and smooth card transitions powered by GSAP.
* **Autosave Lobby & Rooms:** Session storage fallback automatically reconnects players if they reload the browser during an active session.
